# KOHLER AI Studio (2D Prototype)

Welcome to the KOHLER AI Studio project! This is an interactive 2D web configurator built using HTML, CSS, and Vanilla JavaScript. 

## Features
* **Tiered Selection:** Users can browse between Value, Balanced, and Premium tiers.
* **Audio Integration:** Ambient background audio for a premium feel.

## How to Run This Project
Because this project uses modular JavaScript and audio files, it cannot be run by just double-clicking the HTML file. Please follow these steps:
1. Download or clone this repository to your computer.
2. Open the folder in **Visual Studio Code**.
3. Install the **Live Server** extension (by Ritwick Dey) if you don't have it.
4. Right-click on `index.html` and click **"Open with Live Server"**.
5. The project will open in your default web browser.
